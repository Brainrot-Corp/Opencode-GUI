Why a GUI

Same opencode server, friendlier shell around it.

▣Server reuse

Spawns opencode serve as a sidecar and talks HTTP/SSE. No forked agent logic.

⧉Workspaces

Up to 5 directories plus ssh:// remote hosts, each with its own session stream.

◈Glass chrome

Acrylic on Win11, vibrancy on macOS, opaque fallback on Linux. Square flush panels.

✦Permissions

Approve / deny tool calls inline (once / always / reject), abort mid-stream, revert with one click.

❖Editor + terminal

Monaco diffs, xterm dock, git panel, file watcher, voice control via plugins.

⬣Portable

Portable zips ship exe + sidecar + relay. No admin install required.

◍Models + agents

Model / agent / variant / security pickers with per-session memory and subagent viewer.

☾Voice + phone

Mic, VAD + Kokoro TTS, and relay notifications to your phone when runs finish.

✎Plugins + themes

Runtime ESM plugins (7 bundled) and 14 themes, dark + light. Make it yours →
