Make it yours

Plugins, hotkeys, themes — everything lives in plain files, no rebuild.

Plugins

A plugin is a folder with plugin.json + main.js (plus optional styles.css) dropped into %USERPROFILE%\.config\.opencode-gui\plugins\, next to themes.json. Files hot-reload on save; a broken plugin shows a banner and is skipped. Toggling a plugin off disables without deleting.

Trusted local code. Plugins run with full app privileges — only install folders you wrote or reviewed.
{
  "id": "notepad",
  "name": "Notepad",
  "version": "1.7.1",
  "description": "Floating resizable scratch notepad"
}

Plugin API

main.js is plain browser ESM. Its default export activate(api) returns an extension object:

export default function activate(api) {
  return {
    Titlebar: TitlebarBtn,  // icon before the Settings gear
    Overlay: OverlayPanel,  // floating overlay
    // Settings / Sidebar also available
    hotkeys: [
      { id: "toggle", default: "Alt+N", label: "toggle notepad" },
    ],
    onHotkey(id) { if (id === "toggle") toggle(); },
    slash: [
      { name: "note", description: "new scratch note",
        handle: (args) => openNote(args) },
    ],
    info: { keys: [["Alt+N", "toggle floating notepad"]] },
    async init() { /* background work after load */ },
  };
}
  • api you get: invoke (Tauri commands), h/useState/useEffect/useRef (React), settings() (live settings blob), playSound(kind), matchesEvent/normalizeBinding (same hotkey helpers as core, so rebinds apply), t/i18n.register (en/fr/es).
  • UI slots: Settings (drawer section), Sidebar (panel above git), Titlebar (icon), Overlay (floating layer).
  • Voice: parse/describe/exec slot into the spoken-command chain, plus triggers, vocab, lexicon rewrites.
  • Hotkeys: hotkeys[] appear as rebindable pills in the keybinds menu, dispatched via onHotkey.

Bundled examples in default_plugins/: notepad (Alt+N scratch notes), timer, spotify-control, hue-bridge-control, tuya-lights-control (with test.mjs self-check — the full API example), discord-rich-presence, tiktok. To install one:

Copy-Item -Recurse default_plugins\notepad "$env:USERPROFILE\.config\.opencode-gui\plugins\"

Hotkeys

Everything below is rebindable in the app's keybinds menu (a — means unbound). On macOS, Ctrl shows as ⌘.

  • Ctrl+B toggle sidebar · Ctrl+, settings · Ctrl+M mic on/off
  • Ctrl+O open workspace · Ctrl+Shift+W close workspace · Ctrl+Shift+N new window · Ctrl+P pin on top
  • Ctrl+N new session · Ctrl+Tab / Ctrl+Shift+Tab next / previous session · Ctrl+W close session
  • Ctrl+` terminal · Alt+A agents board · Tab cycle agent
  • Ctrl+= / Ctrl+- / Ctrl+0 zoom in / out / reset

Editor line ops (also mirrored by the notepad plugin):

  • Ctrl+C / Ctrl+X copy / cut line (no selection) · Ctrl+Shift+K delete line · Ctrl+L select line
  • Ctrl+/ toggle comment · Alt+↑ / Alt+↓ move line · Shift+Alt+↑ / Shift+Alt+↓ duplicate line
  • Ctrl+Enter / Ctrl+Shift+Enter insert line below / above

System-wide (work even when the app is unfocused): Alt+Space show/hide, Ctrl+Shift+M mic.

Themes

14 built-ins, each with dark + light modes: cyan (default) · latte · matcha · strawberry · sakura · nebula · vaporwave · ember · abyss · citrus · graphite · crimson · tidal · aurora.

Your copy lives at ~/.config/.opencode-gui/themes.json — seeded with the defaults on first launch, hot-reloaded on save (comments allowed). An invalid file keeps the last good set with a toast; Reset restores the built-ins. A theme is a map of id → {name, icon, modes: {dark, light}}, each mode setting CSS vars on <html>:

"ember": {
  "name": "Ember",
  "modes": { "dark": { "vars": { "--accent": "#e0a37f" } } }
}

Unset keys inherit the cyan-dark fallback (--accent: #7fd4d4, --danger: #e08f8f, surfaces, plus --syn-* chat/editor syntax colors).

Session loop

Open a workspace (Ctrl+O, or an ssh://user@host/path remote) → new session (Ctrl+N) → pick model / agent / variant → prompt → approve permissions inline (once / always / reject) → abort mid-stream or revert a bad turn. Model, agent, and security picks persist per session and fall back to last-used globals.

Good to know

  • Workspaces: up to 5 directories plus ssh://user@host/path remotes, each with its own session stream.
  • Permissions: approve/deny tool calls inline, abort mid-stream, revert with one click.
  • Slash commands: built-ins plus any slash[] your plugins contribute — dispatched locally, no server round-trip.
  • State: drafts, models, agents, and UI prefs persist per-session under oc.* localStorage keys.
  • Voice: mic toggle (Ctrl+M) with VAD + Kokoro TTS. GPU voice DLLs are Windows-only; macOS/Linux are CPU-only.
