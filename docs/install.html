install

Up and running in minutes

Pick the artifact for your OS — no Node, no Rust, no build.

Windows 10 / 11 (x64)

  • Recommended: opencode-gui-win11-x64.zip — glass/acrylic build. Unzip anywhere, run opencode-gui.exe.
  • Windows 10: opencode-gui-win10-x64.zip — opaque no-glass build, same features.
  • Portable zips contain opencode-gui.exe + opencode.exe (sidecar) + oc-relay.exe — keep them side by side.
  • Prefer an installer? Grab the .msi from the same release page.
  • WebView2 ships with Windows. SmartScreen may flag the unsigned zip — More info → Run anyway.

macOS 13+ (arm64)

  • Download the .dmg (or .app.tar.gz), drag to Applications.
Unsigned build. First launch: right-click the app → Open → Open. No notarization yet.

Linux (x64 + arm64)

  • .deb for your arch (Debian/Ubuntu), or .AppImage (chmod +x, runs anywhere).
  • Needs system webview:
sudo apt-get install -y libwebkit2gtk-4.1-dev libappindicator3-dev librsvg2-dev patchelf

First run

  1. Launch the app — it starts its own opencode serve sidecar automatically.
  2. Pick a workspace folder (empty = home directory).
  3. Create a session, pick a model, prompt. Approve tool permissions inline.

Troubleshooting

  • Blank window (Linux): missing webkit — install the packages above, restart.
  • Sidecar missing: portable zips must keep all three exes together.
  • Download page shows "offline list": GitHub API rate-limit (60/hr) — use releases directly.
  • Devs: run.sh setup / dev / build (or run.ps1 on Windows) — see README.
