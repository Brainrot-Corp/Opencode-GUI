# Fragile Code Audit — Bound-to-Break Findings

**Date:** 2026-08-30  
**Scope:** `src/hooks/useOpencode.ts`, `src/api.ts`, `src/hooks/useProviders.ts`, `useSettings.ts`, `usePlugins.ts`, `useVoice.ts`, `useSpeech.ts`, `src/lib/sessionStore.ts|busyTracker.ts|workspace.ts`, `src/components/*.tsx` (MessageList, Composer, FileTree, Terminal, GitPanel), `src-tauri/src/lib.rs|pty.rs|voice.rs|git.rs|update.rs|browser.rs|terminals.rs`  
**Focus:** race conditions, error-handling gaps, brittle assumptions, resource leaks, timing fragility — *only* code that will break under real conditions  
**Method:** full read of each file above, manual trace of async lifecycles, SSE state machine, Tauri command boundaries, and storage read-modify-write paths. Line numbers are as-read on 2026-08-30 (off by ±5 if file was reformatted since).

---

## Overview

The app is a Tauri sidecar that wraps `opencode serve` + an SSE stream per workspace. Most fragility concentrates in three seams:

1. **SSE ↔ fetch ↔ busy state** — three sources of truth (`tracker.inflight`, `busyIds` Set, `sessionStore` snapshots) reconciled with grace timers and `busyRef` lagging a render. Mid-turn `session.idle` and `message.completed` used to flap indicators before the grace fix, now guarded but the guard introduces a new queue-drain race.
2. **Workspace directory plumbing** — the `?directory=` query is injected by a `Proxy` around the SDK client (`src/api.ts:33-44`). The proxy captures `directory` at wrap time; later workspace switches leave the singleton client stale.
3. **Rust ↔ JS boundary** — Tauri `async` commands that shell out (`git`, `voice`, `pty`, `update`/`curl`) block the async runtime with `std::thread::sleep` loops, create temp files with low-entropy names, and retry ports / file moves with fixed delays that fail on slow AV or Win10 teardown.

All findings below are reproducible without mocking — either by switching sessions/workspaces fast, letting a turn stream while switching, killing the sidecar, or filling `localStorage` / `TEMP`.
